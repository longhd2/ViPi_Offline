# ViPi Offline - Client

Firmware Client hiện tại:

`3.0.0-alpha3.2`

GitHub Release:

`client-v3.0.0-alpha3.2`

## Firmware

- `VIPI_APP.bin` - OTA firmware.
- `VIPI_FULL.bin` - Full 16 MiB image cho flash lần đầu/recovery.
- `VIPI_SOUNDS.bin` - Sound Pack.

## Metadata

- `latest.json` - ViPi Server dùng để kiểm tra firmware mới.
- `manifest.json` - Thông tin build, SHA256 và partition.
- `VERSION` - Phiên bản Client hiện tại.

Binary firmware được lưu trong GitHub Release tương ứng.
